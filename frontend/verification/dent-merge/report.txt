현재 구현 + 이전 함몰/따라오는 홈 병합

이번에 수정/추가한 제품 파일:
- src/utils/mallangSurface.js: 현재 외곽·당김 위치·색상을 유지하며 높이와 기울기에 따른 함몰 음영 복구.
- src/utils/mallangRelief.js: 같은 깊이에서 파생되는 함몰/주변 융기와 복원 중인 홈의 재사용 높이 버퍼.
- tests/mallangSurface.test.js: 기존 외곽·최대 당김 지점136·팔레트·이동 중 흔적·종료 검사 유지.
  요청한 넓은 홈/깊이에 따른 수명에 맞춰 흔적 밖 배경 확인 위치와 완전 복원 시점만 갱신.
- tests/mallangRelief.test.js: 중복 누적 방지, 연결된 홈, 앞뒤 복원 순서, 본체 이동 좌표, 버퍼 재사용 검사 추가.

보존 범위:
- 현재 입력/반응 모델, 외곽 부풀음, 작은 원의 위치·당김·흡수·재잡기, 본체 물리,
  왁스 파괴, 오디오, 버튼, CSS 파일은 작업 전후 SHA256이 같다(protected-after.json).
- 현재 화면에서 함몰이 이동하는 범위와 최대 당김 지점136을 유지했다.
- 본체 색상과 흰 띠를 추가하지 않는 현재 표현도 유지했다.
- 예전 8단위 반경·10% 음영·340ms 흔적 대신 실제 함몰 깊이의 홈을 표시한다.
  떠난 깊이에 따른260~680ms 복원과 거리별 표본을 사용하여 뒤쪽부터 채워진다.
- 전부 되돌린 작업이 아니다. 다른 현재 변경 사항은 그대로 남아 있다.

검증:
- 작업 전50개 테스트 통과, 변경 후53개 테스트 통과.
- 소스·테스트·설정 파일 전체 ESLint 통과(source-lint.txt).
- ESLint . 명령은 기존 verification/surface-inspection-local 폴더 접근권한 때문에
  파일 수집 단계에서 실패했다(lint.txt). 설정이나 권한을 변경하지 않고 실제 코드 경로를 검사했다.
- 프로덕션 빌드 통과. 기존 앱 청크500kB 초과 경고는 남아 있다(build.txt).
- 고정1000x800 브라우저에서 문지르기, 급회전, 당김·흡수, pointercancel/blur 검사 통과.
- 고정 전 표시 영역이 변하는 검증에서는 입력이 중단되어 처음부터 다시 실행했다.
  입력 중단 처리를 약하게 바꾸지 않았다. 최종5개 실행 결과는 browser-results.json에 있다.
- 마지막 브라우저 콘솔 오류/경고0개.
- 기존 iOS 실기기 미검증 범위는 그대로다. 이번에도 실제 iOS 실행을 했다고 주장하지 않는다.

복구 범위/실행 흐름:
현재 접촉 위치와 깊이 → 현재 화면의 함몰 위치 → 함몰·주변 융기 높이 →
윗왼쪽 광원에 따른 기울기 음영. 떠난 접촉은 떠난 시각과 깊이를 보관해 복원한다.
몸이 이동해도 흔적은 월드 위치에서 되돌려 계산한다. 현재 외곽 경로 안에서만 표시한다.
이 높이 재분배는 렌더링 근사이며 실제3D 부피 보존을 뜻하지 않는다.

직접 확인:
/mallang에서 길게 누른 채 좌우/S자로 문지르기 → 잠깐 멈춰 뒤쪽 홈이 차오르는지 확인 →
바깥으로 당기기 → 놓고 작은 원 흡수 확인. 나머지 조작은 현재 버전과 같다.

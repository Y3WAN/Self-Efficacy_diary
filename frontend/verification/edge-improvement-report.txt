사이버 말랑이 테두리 홀드 개선 — 2026-11-21

프로젝트와 보존 범위
React 19 / Vite 8 / Canvas 2D 기반 프론트엔드의 현재 미커밋 구현을 기준으로 수정했다.
기존 작업은 임시 폴더에 사본과 SHA-256 해시를 보관했다. 관련 없는 기존 변경의 해시는 유지됐다.
CSS, 음향, 왁스 균열 규칙, 몸체 이동 계수, 기존 클릭 시간·깊이, 당김의 최대 반지름·장력 거리는 변경하지 않았다.
새 외부 패키지는 추가하지 않았다. 커밋·푸시는 수행하지 않았다.

원인
1. membraneRadii가 양의 높이와 음의 높이를 모두 양의 외곽 변위로 바꿔 접촉 함몰과 양옆 융기를 구분하지 못했다.
2. 이동할 때마다 지역 dwell을 거리로 감쇠시켰고, 계속 누르는 압력은 별도로 없어서 느린 테두리 이동에서도 깊이가 손실됐다.
3. 접촉점은 반지름 92로 제한됐지만 외곽은 재질에 따라 변했고, 당김은 반지름 94에서 시작해 기준이 서로 달랐다.
4. 음영의 커버리지가 고정 원에 묶여 있어 팽창한 외곽으로 이어지지 않았고, 바깥의 높이 0이 경사와 재질 결합에 개입했다.

수정 파일과 방식
- src/utils/mallangMaterial.js: 부호를 보존한 외곽 변위, 자유 경계의 공간 결합, 지속 홀드 압력과 지역 복원 이력 분리, 실제 외곽의 접촉점 계산.
- src/utils/mallangSurface.js: 자유 경계의 법선 계산과 변형된 외곽에 맞춘 음영 좌표 매핑. 기존 재사용 픽셀 버퍼 유지.
- src/utils/mallangMotion.js: pulledCircle이 현재 방향의 몸 반지름을 선택적으로 받아 전환을 시작하도록 확장. 기본값과 물리 계수 유지.
- src/pages/MallangPage.jsx: 동일한 외곽 기준으로 접촉과 당김을 연결하고 당김 진행도에 따라 활성 눌림을 감소. 개발 모드에만 압력·외곽 진단 추가.
- tests/mallangEdge.test.js: 새 테두리 회귀 테스트 6개.
- tests/mallangSurface.test.js: 이번 목표와 충돌하던 접촉 방향 팽창 조건을 함몰·양옆 융기로 수정하고 외곽 조명 범위를 검증.
- tests/mallang-browser.jsx: 개발용 rim-transition 경로 추가.

핵심 실행 흐름
현재 포인터를 즉시 몸 좌표로 변환 → 현재 몸 외곽에서 접촉점 제한 → 그 외곽부터 당김 진행도 계산 → 당김이 커지는 만큼 활성 눌림 감소 → 높이장 갱신 → 동일한 높이로 외곽과 음영 표시.
지속 압력은 반경 55~80 구간에서 점진적으로 적용하고, 느린 이동에서만 보완한다. 안쪽 입력은 기존 지역 dwell을 유지한다.
속도가 높으면 지속 압력을 넘겨주지 않는다. 지난 노드는 각각 떠난 시각과 깊이로 복원하며, 깊이를 합산하지 않는 기존 홈 계산을 유지한다.
포인터 좌표나 몸체 힘에 보간·필터·입력 지연을 추가하지 않았다. 속도의 감쇠는 재질 압력에만 적용된다.
당김 끝점을 접촉 기준으로 재사용하지 않아 끝점과 앵커가 서로 증폭되는 피드백을 피했다.

시각 검증과 남은 한계
중앙 홀드, 테두리 홀드, 방향 전환, 실제 포인터 해제 직후와 완전 복원 단계의 화면을 직접 관찰했다.
접촉부가 안쪽으로 눌리고 주변 융기의 음영이 외곽까지 이어지는 것을 확인했다. 고정된 원에서 음영이 끊기는 현상은 관찰되지 않았다.
수치 테스트는 연속성·안정성·복원을 검사한다. 화면 관찰은 주요 단계의 모양과 음영에 대한 별도 검증이며 모든 연속 프레임의 감각을 보장하지 않는다.
깊게 누른 채 천천히 이동하는 전체 경로는 DOM PointerEvent 재현으로 검증했다. 실제 포인터는 긴 클릭·드래그·테두리 해제를 따로 검증했으며, 전체 경로를 손으로 연속 조작한 감각과 실기기 터치는 아직 확인하지 않았다.
재질은 2D 높이장 근사다. signedHeight 검증은 기준 원의 부호 있는 높이 적분이며 실제 3D 액체 체적 보존 검증은 아니다.
